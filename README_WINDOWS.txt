Author: Dumitru Cristinel Gordas (GDC)

EN  Free maintenance edition for DaVinci Resolve Studio on Windows (x64). No account, trial, licence code or donation
    is needed and the plugin contacts no server. Windows development of new features is suspended; contributions are
    welcome: https://github.com/gordasgdc/gdc-resolve-encoder
    Install: double-click install.bat (asks for administrator rights), restart DaVinci Resolve Studio, then in Deliver
    choose Format = GDC QuickTime / GDC MP4 / GDC Matroska, Codec = GDC Encoder, Type = the variant you want.
    Status: built from the v1.7.0 sources with the licence code removed; see the project page for whether it has already
    been tested in DaVinci Resolve on Windows.
