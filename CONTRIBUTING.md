# Contributing · Contribuții · Contribuciones

**English.** Issues and Pull Requests are welcome, especially for **Windows** (the code and the CI workflow exist but have not been verified). Before a Pull Request: build on macOS as described in [README.en.md](README.en.md), run `tests/run_mux_tests.sh` and the `pixconv_test` target, and describe what you verified in DaVinci Resolve Studio (version, codec, container, a short clip is enough). Use only content you may redistribute in issues and attachments. The project is maintained occasionally; replies may take a while.

**Română.** Issues și Pull Requests sunt binevenite, mai ales pentru **Windows** (codul și fluxul CI există, dar nu au fost verificate). Înainte de un Pull Request: compilează pe macOS ca în [README.md](README.md), rulează `tests/run_mux_tests.sh` și ținta `pixconv_test` și descrie ce ai verificat în DaVinci Resolve Studio (versiune, codec, container; un clip scurt e suficient). În issues și atașamente folosește doar conținut pe care ai voie să-l redistribui. Proiectul are mentenanță ocazională; răspunsul poate dura.

**Español.** Se aceptan Issues y Pull Requests, sobre todo para **Windows** (el código y el flujo de CI existen pero no se han verificado). Antes de un Pull Request: compila en macOS como en [README.es.md](README.es.md), ejecuta `tests/run_mux_tests.sh` y el objetivo `pixconv_test`, y describe qué verificaste en DaVinci Resolve Studio (versión, códec, contenedor; basta un clip corto). En issues y adjuntos usa solo contenido que puedas redistribuir. El proyecto tiene mantenimiento ocasional; la respuesta puede tardar.
